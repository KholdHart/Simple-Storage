# Simple Storage Smart Contract

This repository contains a simple storage smart contract written in Solidity. It demonstrates how to store, update, and retrieve data on the Ethereum blockchain.

## Features

- **Store a Value**: Save a number on the blockchain.
- **Retrieve the Value**: Fetch the stored number from the blockchain.
- **Update the Value**: Modify the stored number with a new value.

## Prerequisites

To work with this project, you'll need:

- [REMIX IDE](https://remix.ethereum.org/) (or any Solidity development environment).
- A Web3-compatible wallet (e.g., MetaMask).
- Access to an Ethereum network (e.g., a testnet like Goerli or a local blockchain using Ganache).
